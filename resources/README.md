# 🔗 Resources / Kaynaklar

Faydalı bulduğun her şeyin koleksiyonu.

## Önerilen yapı

resources/
├── tools/           # Araçlar ve yazılımlar
├── articles/        # Okumaya değer yazılar
├── videos/          # Videolar / podcastler
├── templates/       # Şablonlar
├── people/          # İlham veren insanlar
└── lists/           # Listeler (kitap, film, vs.)

## İpucu

Sadece "faydalı olabilir" diye ekleme.  
Gerçekten değer verdiğin ve tekrar bakacağın şeyleri koy.
